# 合成大肉鸽 · 游戏站

《合成大肉鸽》官方宣传 + 在线试玩页（合成大西瓜 × 肉鸽）。

- `index.html` — 网站首页（首屏 / 进化链 / 玩法介绍 / 在线试玩）
- `game.html` — 游戏本体（H5 版，首页通过 iframe 嵌入）

## GitHub Pages 部署

1. 把本文件夹的全部文件（含 `.nojekyll`）放到仓库根目录
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`
3. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

以后更新：改完文件重新上传覆盖即可，Pages 会自动重新发布。
